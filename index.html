REFERENCE DESK

Method guide

A quick refresher before you build your system of equations.

V
METHOD 01

Node Voltage Method

Choose a reference node (ground), assign voltages to the remaining essential nodes, then apply Kirchhoff's Current Law (KCL).

Σ I = 0 at each non-reference node

Useful when

  • The circuit has fewer essential nodes than independent meshes.
  • Many branches share the same reference node.
  • Node voltages are the values you need to find.
I
METHOD 02

Mesh Current Method

Assign a current to each independent mesh and apply Kirchhoff's Voltage Law (KVL) around each loop.

Σ V = 0 around each independent mesh

Useful when

  • The circuit is planar and has fewer meshes than essential nodes.
  • Branch currents are the main values you need.
  • Voltage sources make loop equations straightforward.
Ax
THE MATHEMATICS

Solving a linear system

Both methods can be represented as Ax = b, where A contains coefficients, x contains unknowns, and b contains constants. The solver uses Gaussian elimination with partial pivoting.

ACoefficient matrix
xUnknown vector
bConstants vector

How to read the result

  • Unique solution: one value for every unknown.
  • Singular system: equations are dependent or inconsistent; a unique solution cannot be returned.
  • Power balance: for a complete list of elements, total absorbed power should approximately equal total delivered power.
